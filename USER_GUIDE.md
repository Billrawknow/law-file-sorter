# Document Sorter: Quick Guide

**What it does:** tidies your downloads folder by moving each file into the right place:

| Folder | What goes there |
|---|---|
| **Contracts** | Word documents (.docx, .doc) |
| **Evidence** | Photos (.jpg, .jpeg, .png) |
| **Filings** | PDFs, including scans |
| **Correspondence** | Emails and text notes (.eml, .txt) |
| **Other** | Everything else |

## How to sort your files

1. Double-click **Document Sorter** on your desktop.
2. The first time only, click **Choose folder...** and select your downloads folder. The app remembers it after that.
3. Click **1. Preview**. You'll see a list of every file and the folder it will go to. **Nothing is moved yet.**
4. **Not sure what a file is?** Double-click it in the list. It opens in the normal program (photo viewer, Word, Acrobat), so you can check it before anything moves.
5. **Want a file somewhere else?** Click it (hold **Ctrl** to pick several), then:
   - **Move to ▾:** choose a different folder, e.g. send a scanned contract PDF to *Contracts* instead of *Filings*.
   - **Move to ▾ → New folder...:** type a name to file documents by client, e.g. `Caleb Otieno` or `Clients/Jane Wanjiru`. The folder is created when you sort.
   - **Move to ▾ → Choose another folder...:** pick any existing folder on the computer, e.g. `D:\Clients\Caleb Otieno`.
   - Folders you've used recently appear in the **Move to ▾** menu, so the next document for the same client is one click.
   - **Don't move:** leave it where it is for now.
   - Changed your mind? **Move to ▾ → Automatic** puts it back to normal.

   Files you've changed show in **blue**, files moved by a saved rule in **purple**, and files staying put show in **grey** as *(stays here)*.
6. When the list looks right, click **2. Sort now**, then **Yes**.
7. Done. Each file in the list turns green. Double-click any of them to open it in its new folder. Click **Open folder** to see your tidy folders.

## Saved rules: file a client's documents automatically

Tired of choosing Caleb's folder every time? Make a rule once:

- **From a file:** in the preview, click one of Caleb's files, then **Always do this...**. Change the text to just the part that's always in his files, e.g. `Caleb`, choose the folder, e.g. `Clients/Caleb Otieno`, and click **Save rule**.
- **From the Rules window:** click **Rules...**, then **Add...**, and fill in the same two boxes.

From then on, **any file whose name contains "Caleb"** goes to Caleb's folder automatically, including during the nightly automatic sort. Capital letters don't matter.

- In the preview, files moved by a rule show in **purple** with the rule next to them.
- You can still change a single file by hand with **Move to** or **Don't move**. Your choice wins over the rule for that sort.
- **Rules...** lets you **Edit**, **Delete** or reorder rules. If a file matches two rules, the one **higher in the list** wins.

## Good to know

- **Nothing is ever deleted or overwritten.** If a file with the same name is already in the folder, the new one is saved with a number, e.g. `scan001 (2).pdf`.
- **A file shows in red, "Not moved".** It's open in Word or Acrobat. Close it, then click Preview and Sort now again.
- **A file you chose "Don't move"** stays in the folder, and next time it will be suggested again, so you can sort it once you've decided.
- **"Where did my file go?"** Click **Open log**. It lists every file that was moved, when, and where to.
- **Your files never leave this computer.** The app works without the internet.
